# AI Portfolio IAS

Approved Portfolio 7.0 visual showcase for the Intelligence Automation Systems project set.

This Next.js site presents Projects 1-8 only, preserving the rainbow project identity, glowing cards, 3D orb system, maturity path, click-to-expand DNA modal, real-world value section, and live demo links.

## Projects Included

- Project 1: AI Systems Lab
- Project 2: AI Deployment Console
- Project 3: AI Workflow Automation Assistant
- Project 4: AI RAG Knowledge System
- Project 5: AI Revenue Intelligence Assistant
- Project 6: AI Service Operations Intelligence System
- Project 7: AI Enterprise Orchestrator
- Project 8: AI Autonomous Operations Command Center

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` or the port shown by Next.js.

## Production Check

```bash
npm run lint
npm run build
```

## Deployment Notes

- Keep `.env.local` out of Git.
- Deploy with Vercel after the production build passes.
- Preserve the approved Portfolio 7.0 visual identity when making future changes.
